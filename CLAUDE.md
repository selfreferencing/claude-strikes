# Claude Strikes! (pilot)

A research pilot on whether Claude agents pay to join a strike. If you are asked to review it, follow `REVIEWING.md`.

- Work from `pilot/`. Tests and the freeze check run offline (commands in `README.md`).
- Never run anything with `--live`. Live runs spend money on the owner's OpenRouter key, which is not in this repository.
- Do not edit the files listed in `pilot/FREEZE.md` or `pilot/FREEZE-research-grade.md`; the freeze check compares them with their fingerprints.
